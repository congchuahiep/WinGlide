# Privacy Policy

This policy applies to the WinGlide application for Windows 11 ("the Application"), operated by congchuahiep ("the Service Provider").

Effective date: 2026-09-22

## Data collection

The Application does not collect, store, transmit, or share any personal data. There are no analytics, no telemetry, no advertising, and no third-party SDKs included in the Application.

## Local data

The Application stores its settings locally on your device in the Windows AppData folder (`%APPDATA%\WinGlide`) under your user profile. Log files are also written locally to the same folder. This data never leaves your device.

## Network access

The only network request the Application can make is an optional check for a new version against the public GitHub Releases API (api.github.com), triggered when you click "Check for updates" in the Settings window. This request does not send any personal or device-identifying information.

## Permissions and system access

To provide its features, the Application uses Windows APIs on your device, including UI Automation, a low-level keyboard hook (for Win-involved hotkeys such as Win+1..Win+9), and reads a few Windows registry values. All of this happens locally on your device; no data is transmitted.

## Children

The Application is not directed at children and does not knowingly collect any information from anyone, including children.

## Changes

If this policy changes, the updated version will be published at this page with a new effective date.
